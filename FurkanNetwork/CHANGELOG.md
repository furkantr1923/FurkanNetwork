# Değişiklik Günlüğü

## [1.0.0] — İlk sürüm
### Eklendi
- Panel: bağlantı durumu, tür, yerel/genel IP, DNS, hızlı erişim
- IP Bilgisi: IPv4/IPv6, genel IP (ipify), ağ geçidi, DNS sunucuları, Özel DNS
- DNS sorgusu: A/AAAA ayrı sorgu, süre ve hata kodları
- Ping: başlat/durdur, min/ort/maks, paket kaybı, jitter, grafik; ICMP yoksa açıkça etiketlenen TCP 443 yedeği
- Traceroute: TTL tabanlı, en fazla 30 atlama, desteklenmeyen durumların açıklaması
- Ağ Bilgisi: Wi-Fi/mobil durum, sinyal, frekans/kanal, isteğe bağlı SSID
- SSL sertifika bilgisi, isteğe bağlı indirme hızı testi
- Çevrimdışı: IPv4 alt ağ hesaplayıcı, SHA-256 (metin + dosya), şifre üretici
- Geçmiş: filtre, ayrıntı, silme, paylaşma, .txt dışa aktarma
- Ayarlar: koyu/açık tema, genel IP otomatik sorgu, varsayılan ping sayısı
- Windows için tek komutla APK üreten `apk-uret.ps1`
