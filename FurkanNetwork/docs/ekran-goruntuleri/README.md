# Ekran görüntüleri

Uygulamayı telefonda çalıştırdıktan sonra ekran görüntülerini bu klasöre şu adlarla ekleyin:

- `panel.png` — Panel
- `ping.png` — Ping sonucu (grafikli)
- `traceroute.png` — Traceroute
- `araclar.png` — Araçlar listesi
- `ag-bilgisi.png`, `ssl.png`, `alt-ag.png`, `gecmis.png` (isteğe bağlı)

Ardından ana `README.md` içindeki "Ekran görüntüleri" tablosunu yorum satırındaki örneğe göre güncelleyin.
> Ekran görüntülerinde genel IP adresinizi ve Wi-Fi adınızı (SSID) **karartmayı** unutmayın.
